Remedy Mesh Architecture

Cloud Run runs the app and the orchestrator. Each of the 8 agents runs as its own managed service on Vertex AI Agent Engine. Verdicts and allocations stay in deterministic code, agents read the case data from Firestore, and a person approves every action that leaves the system.

One confirmed case, end to end

  1. Eleanor opens a case. The run streams live to her screen over SSE.
  2. Layer 1 runs on Agent Engine. The Interpreter, Investigator and Verifier read the case's complaints, lots and policy from Firestore, each passing its output to the next.
  3. The verdict gate decides. Deterministic code checks the six evidence criteria. The Verifier audits that verdict independently, and any disagreement is flagged for a person.
  4. Layer 2 negotiates. The Supplier Offer Agent runs once per supplier, scoped to that supplier's own cost and capacity. The OEM Counter Agent counters each offer and never sees a rival's bid.
  5. A real phone call confirms each deal. Twilio places the call and the Call Understanding Agent reads every spoken reply.
  6. A decline is re-sourced live. The reserve supplier is re-quoted and countered, and the Re-source Narration Agent explains the choice.
  7. Drafts reach the approval queue. The purchase orders and the NHTSA Part 573 amendment wait for James.
  8. James approves. Only then does Gmail send the PO or file the amendment. He also acknowledges declines and decides escalations.

What runs where

Cloud Run
The app, the orchestrator, the deterministic verdict and allocation code, the Twilio webhook and document drafting.
Agent Engine
8 ADK agents, each a separate managed service. Each turn gets its own session, so no state carries over between suppliers.
Gemini
2.5 Flash for most turns. 2.5 Pro for the Investigator and Verifier.
Firestore
9 cases, 503 complaints, 30 production lots, 7 campaigns, 4 parties, 50 dealers, plus the policy thresholds.
Isolation
A supplier sees only its own numbers. The OEM sees only a count of alternatives.
Humans
Nothing leaves the system until the Approver signs off.

All companies, VINs and complaints are synthetic, modelled on real NHTSA recall patterns.
